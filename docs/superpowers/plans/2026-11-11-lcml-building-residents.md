# LCML 한 건물 보기와 상주 에이전트

사용자 요청: 전체 보기를 실제 건물처럼 세로로 쌓고, 각 공간에 등록된 사람이 쉬는 동안에도 보이게 한다. 누락된 실제 실행 세션을 찾아 수집한다. 이전 2×2 전체 보기와 ‘세션이 없으면 사람도 없음’ 규칙을 대체한다.

## 기준

- 1층 제품실(지니), 2층 고객실(고딘), 3층 비즈니스실(SAM), 4층 대표실. 네 개의 방이 하나의 연결된 골조 안에 놓인 건물 단면이다. 각 층 내부 보기는 기존 개별 공간을 유지한다.
- OpenClaw 현재 등록 원천 `agents.entries`의 7명과 사용자가 정의한 대표 자리를 `residents`로 표시한다. 디렉터리만 남은 과거 에이전트는 포함하지 않는다.
- 상주 인원은 실행 세션과 구분한다. 같은 에이전트의 대표 세션은 상주 인물에 연결하고 하위/동시 실행은 별도 인물로 표시한다. 대표 자리는 사람의 온라인 상태를 주장하지 않는다.
- 수집은 10분, 화면 재조회는 30초, 관측이 12분을 넘으면 마지막 사람은 남기고 움직임을 멈춘다. 확인되지 않은 상태를 작업이나 대기로 꾸미지 않는다.
- Codex 로컬 SQLite의 실행 turn과 같은 turn의 item 시간 메타데이터를 읽는다. 대화, 제목, 프롬프트, 비밀값, 로컬 경로를 공개하지 않는다. 테스트용 실행 세션을 만들지 않는다.
- 등록 원천/실행 원천 실패를 표시한다. 마지막 명단은 실패 시 보존하되 재관측한 것처럼 시간을 갱신하지 않는다.

## 작업

1. 수집기: 등록된 7명 + 대표 자리, hj 4층/taxops 3층 교정, Codex 실행/부모 관계 수집, 의미 있는 회귀 검증.
2. 비주얼/UI: 하나의 4층 건물 이미지, 층별 클릭 진입, 인물/벽면 보드 오버레이. 상주 인물과 세션 연결, 중복 방지, 질문자는 대표실 대기열, 상주 인물은 세션 종료 뒤 자리에 남는다.
3. 검증/배포: 실제 데이터로 모든 층 인물 표시 확인, 활성/유휴/오래된 관측/수집 실패/동시 실행 회귀, 데스크톱 및 모바일 스크린샷. 수집기 백업 패치 갱신, 기존 기능 브랜치에 기록, 승인된 기존 공개 URL에 적용.
