# 모두의정책 — Policy-first Atlas 화면 기준

화면 역할: 정치인 10명의 **발표 당시 정책 사례**를 먼저 읽고, 중앙행정기관 44곳의 기본 정보를 같은 화면에서 탐색한다. 정책과 기관의 담당·집행 관계는 검증 자료가 없어 표시하지 않는다. 사용자의 정책 중심 방향을 구현한 시제품이며 CMO의 브랜드 확정이나 고객 성과 검증은 아니다.

## 첫 화면의 정보 위계

- 남색 `#090e27` 배경의 Blender 입체 개념도에 정책 사례 10개를 5×2 노드로 먼저 올리고, 아래에 19부·6처·19청의 독립적인 세 군집을 배치한다. 각 정책 노드에는 인물·정책명·연도·발표 당시 단계가 보인다. 정부 계층도 레퍼런스는 위계와 탐색 방식만 참고하며, 정책→기관 화살표는 그리지 않는다.
- Blender 장면은 구조와 입체감을 제공하지만 이름·상호작용·포커스는 HTML을 사용한다. 각 군집은 기관 소재지·상하 지휘관계·정치 성향·현재 정책 상태를 뜻하지 않는다. 국회는 입법기관으로 장면의 중앙행정기관 군집에 포함하지 않고 별도 참고 링크로만 둔다.
- 인물 카드를 누르면 정책 요약·단계·당시 소속·원문/보도/법령 검색·저장 기능을 **같은 화면의 네이티브 모달**에 표시한다. 기관을 누르면 명칭·유형·명단 확인일·공식 자료 종류를 **별도 모달**에 표시한다. 외부 링크는 두 모달 안의 보조 동선이다.
- `showModal()`의 배경 차단과 포커스 트랩을 이용하고, 닫기·Escape·선택 요소 포커스 복귀를 검증한다. 저장으로 버튼이 교체돼도 동일한 정책 카드에 돌아간다. 320/375/414/768/1440px에서 가로 넘침과 모달 닫기 버튼 가림이 없어야 한다.
- JS가 없거나 스크립트가 실패하면 정책 10건은 원문 링크, 기관 44곳은 공식 링크로 남는다. 이미지가 로드되지 않아도 목록을 읽을 수 있다. 모바일 기관 목록의 마지막 항목까지 키보드/터치로 접근한다. `prefers-reduced-motion` 및 보이는 포커스를 유지한다.

## 그래픽·자료 경계

- `scripts/render-policy-diagram.py`, `scripts/render-policy-diagram-mobile.py`는 데스크톱·모바일 전용 Blender 장면과 PNG를 생성한다. README의 Pillow 명령이 두 WebP를 변환한다. 화면에서는 각 뷰포트에 맞는 정책 노드 구도만 겹치고, 위치가 어긋나는 기관 받침대는 부드럽게 숨긴 뒤 HTML의 독립적인 세 군집이 기관 선택을 제공한다. 이미지 요청이 실패해도 HTML 노드와 목록이 남는다. 외부 WebGL·자동 네트워크 요청은 없다.
- 정책 자료 확인일(2026-11-14)과 기관 명단 확인일(2026-11-16)을 구분하고, 정부 기구도의 옛 대검찰청 항목을 공소청·중대범죄수사청 공식 사이트로 보정했음을 밝힌다. 정책 효력과 기관 현행 업무는 자동 갱신되지 않는다.
