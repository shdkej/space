# 모두의정책 — Institution Atlas 화면 기준

화면 역할: 국회와 중앙행정기관(부·처·청)의 공식 정보를 한 장면에서 찾고, 별도의 정책 사례·브라우저 저장으로 이어진다. 이번 구현은 사용자 취향에 따른 화면 개선이지 CMO의 브랜드 확정이나 고객 성과 검증이 아니다.

## 단일 장면

- 첫 화면은 남색 `#090e27`·라일락 강조, Blender로 제작한 입체 한국 지형·국회 건축 모형, 백색 디렉터리의 대비로 구성한다. 이전 장식용 도시 히어로와 별도의 의회 지도는 표시하지 않는다.
- 국회는 입법기관 링크 한 개로, 중앙행정기관은 19부·6처·19청 44개를 유형별 링크 목록으로 같은 프레임에서 제공한다. 기관 목록의 열 순서는 소재지를 나타내지 않는다. 지형은 KOSTAT 2013 단순화 행정경계 기반 개략 표현이며 건축 모형은 강조를 위해 확대했다.
- 정부조직관리시스템의 명단에는 옛 대검찰청 항목이 남아 있어 이를 제외하고 현행 공소청·중대범죄수사청 공식 사이트를 보정한다. 이 보정은 `scripts/sync-institutions.py`에서 명시하고, 공식 명단이 바뀌면 자동 중단해 재검토한다.
- 디렉터리는 검색·유형 필터·키보드 링크로 탐색한다. 이미지가 로드되지 않아도 기관 링크와 국회 링크는 남는다. 정책 사례 10건과 국회·광역의회 18개 참고 링크는 별도 섹션으로 보존한다.

## 그래픽 제작과 배포

- `scripts/render-institution-atlas.py`를 Blender 5.3에서 실행하면 `scripts/institution-atlas.blend` 및 PNG를 생성한다. 웹에는 최적화한 `dist/assets/institution-atlas.webp`만 포함한다. 폰트·그래픽은 자체 호스팅하고 WebGL이나 외부 자동 요청은 사용하지 않는다.
- 320/375/414/768/1440px에서 가로 넘침·국회 링크 가림·정책 섹션 겹침을 검사한다. 모바일에서는 지형 다음에 필터와 스크롤 가능한 목록을 두며 링크 터치 높이를 최소 44px로 맞춘다. `prefers-reduced-motion` 및 보이는 키보드 포커스를 유지한다.
- 기관 명단의 출처·확인일과 개편 보정을 화면 하단에 밝힌다. 이미지의 광원·색상은 정치적 성향, 실시간 정책 상태, 실제 기관 좌표를 뜻하지 않는다.
