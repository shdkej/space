# 모두의정책 — 은하수 탐색과 한국형 제도 윤곽

화면 역할은 **탐색(Explore)**이다. 먼저 정치인 10명의 발표 당시 정책 사례를 발견하고, 다음 화면에서 한국 국가기관의 큰 구조와 중앙행정기관 44곳의 이름을 탐색한다. 이는 사용자 취향에 따른 구현 초안이지 CMO의 브랜드 확정이나 고객 성과 검증이 아니다.

## 히어로: 점에서 사례까지

- 어두운 남색 배경에는 Blender로 렌더한 불규칙한 별무리의 깊이감만 둔다. 행성·원형 궤도·중심 허브·정렬된 받침대는 쓰지 않는다. 이미지가 없어도 네이티브 정책 링크/버튼과 텍스트는 남는다.
- 각 정책 표식은 **고유한 점 → 가는 선 → 작은 원형 이름 아바타 → 인물명·정책명·연도·당시 단계**로 끝난다. SVG 점·선은 각 HTML 대상 안에 소유하므로 필터·저장 후 재렌더에도 다른 인물로 이어지지 않는다. 아바타는 실제 인물 사진을 가장하지 않는 이름 배지다. 검증되지 않은 초상 사진이나 합성 얼굴은 쓰지 않는다.
- 점과 선은 해당 사례의 *찾기 표식*이다. 인물 간 관계, 정책의 발안·집행, 정치인과 기관의 담당 관계를 뜻하지 않는다. 정책마다 참여 단계가 다르며 현재 효력은 자동 갱신하지 않는다.
- 넓은 화면에서는 열 개의 표식을 불규칙한 밀도로 흩고, 768px에서는 엇갈린 2열, 320–414px에서는 읽을 수 있는 1열 흐름을 유지한다. 화면 폭 때문에 아바타를 숨기거나 작은 글자로 밀어 넣지 않는다. 터치 대상·포커스·모달은 HTML이 소유한다.

## 히어로 아래: 한국 제도의 큰 윤곽

- 첨부한 미국 조직도는 **전반적인 윤곽·위에서 아래로 읽는 리듬·가는 분기선**만 참고했다. 미국의 연방–주–지방, 선거인단, 거부권·임명 화살표와 기관명을 한국 제도에 복제하지 않았다.
- `국민(주권자) / 대한민국 헌법`에서 `입법·국회`, `행정·정부`, `사법·법원`이라는 **개략 범주**를 읽는다. 이는 모든 헌법기관·정부기관의 완전한 조직도나 지휘·소속 관계도가 아니다. 헌법재판소·선거관리위원회·지방자치는 중앙행정기관의 하위로 그리지 않고 별도 참고 범주로 둔다.
- 행정 영역 안에 부 19·처 6·청 19 이름을 얇은 라인과 타이포그래피로 바로 열거한다. 독립된 목록 상자 3개보다 전체 조직도 윤곽을 먼저 보이게 하되, 부·처·청 사이에 임의의 상하 명령 관계나 각 정책의 담당 기관을 연결하지 않는다. 44곳 모두 검색·유형 필터·기관 모달로 접근할 수 있다.
- 넓은 화면에서는 국민·헌법·입법·행정·사법을 한 가로줄에 놓고, 바로 아래 기관명은 유형별 3·1·3개의 읽기 열로 펼친다. 이 나란한 배치는 기관의 위계가 아니라 한눈에 비교하기 위한 탐색 배치다. 좁은 모바일에서는 글자를 줄여 44곳을 강제로 한 화면에 넣지 않고 세 갈래 다음에 한 열로 읽는다.

## 구현·검증 경계

- `dist/galaxy.css`가 새 히어로와 개략도를 소유하고 기존 `dist/styles.css`는 공통 헤더·모달·저장 화면을 유지한다. 실제 Blender 소스는 `scripts/render-galaxy.py`, 편집 가능한 `scripts/galaxy.blend`, 배포 이미지는 `dist/assets/galaxy.webp`. 오래된 받침대 장면은 재현 자료로만 남기고 새 화면은 호출하지 않는다.
- `data.js`의 10개 출처와 `institutions.js`의 44개 기관 링크를 JS 없는 HTML에도 남긴다. 두 네이티브 모달, Escape·포커스 복귀, 메모·저장·내보내기, 이미지 실패 대체 동작은 기존 기능을 유지한다.
- 출시 전 320/375/414/768/1440px에서 점–선–아바타 끝점·라벨 충돌·클릭·가로 넘침, 아래 한국형 윤곽, 44번째 기관의 키보드 접근, 무JS·이미지 실패를 검증한다. 로컬 검사, 독립 시각 검토, 배포 성공, 라이브 자산 일치는 각각 별개로 기록한다.
