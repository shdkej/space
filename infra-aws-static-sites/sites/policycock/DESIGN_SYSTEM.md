# 모두의정책 — 한 장의 정책·기관 인덱스

2026-11-16 사용자 교정: “44곳이 꼭 다 노출될 필요는 없는데 전체를 한 맵에 나타낸다는 느낌.” 이전 Civic Ledger의 **1440×900에서 54개 이름 전부 노출** 기준은 폐기한다. 사용자 취향과 고객 성과의 최종 판정은 별개다.

## 읽는 순서와 성공 조건

- 첫 조망면은 실제 정책 사례 10건의 **이름·발표 당시 단계**, 별도 자료인 중앙행정기관 **44곳의 세 유형(부 19·처 6·청 19)**, 전체 기관명으로 이동하는 경로를 한 화면에서 보여준다. 두 자료를 가상의 담당·집행 관계나 기관 간 지휘 관계로 연결하지 않는다.
- 1440×900에서 위 조망면 전체가 스크롤 없이 들어오고, 각 정책이 클릭·키보드로 열려야 한다. 44개 기관명은 같은 페이지 바로 아래에 **기본 상태로 모두 펼쳐** 읽는다. 320/375px은 범위와 두 진입점을 먼저 본 다음, 정책과 기관을 순차 탐색한다. 모바일 한 화면에 54개 이름을 축소해 넣지 않는다.
- 수치와 문장은 데이터 원장의 실제 범위만 말한다. ‘청년기본소득 2019 시행 사례’와 ‘육아휴직 3년 2021 공약’은 발표 당시 사례의 차이를 보여주는 카피이며 **현재 효력**을 단정하지 않는다. 계열도 발표 당시 분류이지 현재 당적·정책 이념을 뜻하지 않는다.

## 시각 결정

- Supahero 갤러리의 실제 Anubi 사례에서 **큰 문장 하나가 화면을 이끄는 위계**를 참고했다. 원본의 캐릭터·그림·배치나 브랜드 이미지는 가져오지 않는다. 이 사이트의 주인공은 정책명과 기관 유형 그 자체다.
- 원칙: 크고 직설적인 한글 표제 1개, 작은 정보 표제·두 묶음의 실제 사례 10건·세 기관 유형의 같은 조망면, 전체 명단으로 이어지는 스크롤. 장식 숫자 카드·3D 서류 더미·허위 연결선·영문 장식 라벨을 없앤다.
- 단일 `dist/index.css`가 화면과 두 대화상자의 스타일을 소유한다. `:root`의 `--page #fff`, `--ink #17231f`, `--soft #4c5852`, `--line #bac9c0`, `--line-light #dce5dd`, `--signal #146049`, `--quiet #e5f1e9`; 자체 호스팅 Pretendard Variable. 강조색은 정당이나 현재 시행 상태의 암호가 아니다.
- OpenPencil에서 1440px 편집 시안을 만들고 `design/openpencil/policycock-editorial-index.svg`로 출력했다. MCP의 FIG 저장·PNG 출력은 `memory access out of bounds`로 실패했으므로 **새 `.fig` 원본이 저장됐다고 주장하지 않는다**. HTML의 실제 내용·반응형 결과는 브라우저 캡처로 검증한다. 이전 Blender `.blend`와 PNG는 제작 이력으로 보존하지만 새 화면에서 사용하지 않는다. 3D 장식을 계속 노출하면 사용자가 지적한 AI 같은 인상과 정보 방해가 반복된다는 판단이다.

## 보호 기능과 판정

- 정책 10건과 기관 44곳의 JS/무JS 링크, 단계·연도·출처, 검색·필터, 두 대화상자, Escape·포커스 복귀, 관심 저장·메모·JSON 내보내기, 국회·17개 광역의회 링크를 유지한다. 기관 정적 목록은 `scripts/sync-institutions.py`가 소유한다.
- `npm run check`와 `BROWSER_CDP=http://localhost:9222 npm test`로 1440×900 한 장의 범위, 320–1440px 가로 넘침·겹침, 54건 대화상자/URL, JS 비활성 링크, 모바일 마지막 기관을 확인한다. 테스트 숫자는 디자인 만족의 증거가 아니다. 실제 스크린샷을 따로 읽고, 배포 후에는 공개 도메인·전 파일 바이트 일치까지 다시 확인한다.
- 외부 원문과 기관 명단은 확인일 이후 바뀔 수 있다. 화면의 현재 정책 효력 및 사용자의 디자인 선호에 대한 실사용 검증은 포함하지 않는다.
