# 모두의정책 — Urban Glass 화면 기준

화면 역할: 방문자가 실제 제공되는 정책 사례와 의회 원문으로 들어가는 출발점을 찾는다. 첫 장면의 도시 모형은 *상징*이고, 두 번째 장면의 한국 지도가 실제 의회 링크를 제공한다.

## 시각 구조

- 도입: 짙은 밤색 `#0a112b` 바탕, 흰색 타이포, 라일락 `#e2d7ff` 강조. 도시 모형과 유리 조형물은 `assets/urban-glass.svg`에서 한 번만 사용한다. 사진 레퍼런스의 분위기를 재해석한 자체 제작 SVG이며, 데이터 시각화가 아니다.
- 탐색: 종이색 `#f5f6fb` 위에 흰 지도 캔버스, 남색 잉크 `#17213d`, 보조 글자 `#59657c`, 경계 `#d9deeb`. 실제 한국 지도·의회 핀은 장식 위에 중첩하지 않고 별개 영역에 둔다.
- 계열: 민주당 파랑 `#345fae`, 보수 계열 붉은색 `#995665`는 기존 사례 구분에만 쓴다. 도시 건물의 색을 정치·정책 적용 지역으로 해석하게 하지 않는다.
- 글꼴: 자체 호스팅 Pretendard Variable. 제목은 촘촘한 자간과 2단 위계, 안내 문장은 명료한 실제 제공 범위. 하이라이트 문구가 진짜 CTA를 가리지 않는다.
- 레이어: SVG 장식은 `aria-hidden`/`pointer-events:none`; 핀과 필터·저장 버튼은 독립적인 포커스/클릭 영역. 글라스는 인터랙션 카드 전체에 남발하지 않고 첫 장면의 한 오브젝트로 제한한다.

## 상태·모바일·접근성

- CTA `정책 사례 살펴보기`는 실제 `#atlas`로 이동한다. 역사적 사례/당시 소속/현재 제도 아님을 탐색 구역과 상세에 남긴다.
- 320/375/414/768/1440px에서 가로 넘침, 지도 핀 클릭 가림, 지도·상세 겹침을 검사한다. 모바일에서는 제목/CTA가 먼저, 도시 이미지는 그 아래, 지도·사례 목록은 별도 섹션으로 이어진다.
- 주요 터치 대상은 44px 이상; 키보드 포커스 윤곽과 `prefers-reduced-motion` 대체를 유지한다. 외부 이미지 CDN이나 WebGL 없이 자체 호스팅 SVG로 렌더한다.

디자인은 개인의 명시적 취향 요청을 반영한 이번 화면 구현이지, CMO의 장기 브랜드 확정이나 고객 성과 검증을 뜻하지 않는다.
