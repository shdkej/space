# 모두의정책 — 직접 탐색하는 정책 공간

2026-11-18 사용자는 [Threads 참고 영상](https://www.threads.com/@bsd_funneldding/post/Dc-GbPOk3Gc) 같은 3D 인터랙티브 화면이 원한 스타일이라고 교정하고 “개선해주고 진행해서 배포해줘”라고 요청했습니다. **이 제품에서는 실제 3D 장면을 첫 탐색 화면으로 사용합니다.** 이전 문서의 ‘3D 장식 제거·텍스트만 주인공’ 규칙은 이번 요청으로 대체합니다. 참고의 어두운 색·키보드 외형을 모든 제품에 대한 사용자 선호로 일반화하지 않습니다.

2026-11-16의 “44곳이 꼭 다 노출될 필요는 없는데 전체를 한 맵에 나타낸다는 느낌”도 유지합니다. 첫 화면에 54개 이름을 전부 축소해 넣는 대신 전체 범위를 보여주고 선택한 항목을 가까이 읽습니다.

## 장면과 읽는 순서

1. 첫 화면은 `정책을 펼쳐보세요.`라는 표제, 실제 3D 정책 조각 10개, 회전·선택 안내와 조작부를 보여줍니다.
2. 조각을 선택하면 카메라가 해당 위치로 접근하고 HTML 요약에 정책명·인물·연도·발표 당시 단계가 나타납니다. `내용과 출처`는 기존 상세 대화상자, `관심 저장`은 같은 저장 데이터로 연결합니다.
3. `전체로 돌아가기`로 조망 위치를 회복합니다. 펼침·모음과 낮·저녁 조명은 실제 물체·카메라·빛을 바꾸며, 평면 이미지 교체로 대신하지 않습니다.
4. 다음 영역에서 정책 10건을 목록으로 읽고, 별도의 중앙행정기관 44곳(19부·6처·19청)을 검색·선택합니다. 국회·17개 광역의회 참고 링크와 내 관심 정책을 유지합니다.

정책 사례와 기관 목록 사이의 담당·집행 관계는 표시하지 않습니다. 물체의 위치·높이·크기·색과 조립 구조는 지리, 정치 성향, 현재 효력, 중요도 순위, 정부의 지휘 관계를 의미하지 않습니다.

## 시각 언어

- **장면:** 옅은 화이트 바탕, 짙은 녹색 받침, 세라믹 정책 조각, 금속 테두리와 부드러운 접촉 그림자. 형태·재질·빛이 공간감을 만들고 화면 밖 장식은 줄입니다.
- **서체:** 자체 호스팅 Pretendard. 표제는 첫 행동을 알리고, 정책명·단계는 작은 장식 글자가 아니라 읽을 수 있는 HTML 텍스트로 둡니다.
- **색 토큰:** `--page #f7f8f2`, `--ink #172b25`, `--soft #626e65`, `--line #d0d6cc`, `--line-light #e2e6dc`, `--signal #205442`, `--quiet #eef1e7`. 정당·시행 여부의 암호로 색을 사용하지 않습니다.
- **선택:** 선택한 조각의 색·높이와 HTML 버튼 상태를 함께 바꾸고 `aria-pressed`로 전달합니다. hover만으로 핵심 정보를 숨기지 않습니다.
- **조작부:** 모음/펼침, 낮/저녁, 전체 보기와 회전 조작은 짧은 한국어 라벨과 선택 상태를 제공합니다. 화면 카피에 WebGL·렌더러·테스트 같은 구현 용어를 노출하지 않습니다.

`dist/index.css`가 HTML 화면을, `dist/policy-scene.js`가 물체·카메라·조명을 소유합니다. Three.js 0.187.0과 addon은 같은 출처의 `dist/vendor/three/`에서 불러옵니다. 기존 Blender 정지 이미지와 OpenPencil 시안은 제작 이력이며 현재 장면의 런타임 자산이 아닙니다.

## 반응형과 조작

- 데스크톱: 정책 조각 5열×2행. 첫 화면에서 장면의 범위·조작·정책 선택 경로를 인식할 수 있어야 합니다. 카메라 회전 범위를 제한해 글자가 뒤집히거나 바닥 아래로 내려가지 않게 합니다.
- 1100px 이하: 3열×4행에 정책 10개를 배치합니다. 빈 칸을 새 데이터처럼 채우지 않으며 모바일 한 화면에 기관 44개를 욱여넣지 않습니다.
- 모바일에서는 세로 스크롤이 기본입니다. `돌려보기`로 회전을 켜고 다시 스크롤로 돌아갈 수 있어야 합니다. 정책을 누르는 행동과 드래그를 구분합니다.
- 회전·펼침·선택·화면 크기 전환 후에도 HTML 라벨과 조각 위치가 맞아야 합니다. 요약 패널·상단 메뉴·하단 조작부가 선택 대상을 가리지 않아야 합니다.
- `prefers-reduced-motion`에서는 카메라·조각 전환을 즉시 반영합니다. 자동 회전을 기본으로 두지 않습니다.

## 접근성과 실패 시 동작

정책 라벨은 실제 HTML 버튼이며 Tab과 Enter/Space로 선택합니다. 캔버스는 보조 기술에서 숨기고, 선택 변화는 짧은 live region과 HTML 내용으로 전달합니다. 상세 대화상자의 포커스·Escape·선택 요소 복귀를 유지하고 터치 영역·대비·화면 넘침을 직접 확인합니다.

WebGL 생성·모듈 로딩 실패나 context loss가 나면 장면 조작부를 비활성화하고 정책 목록으로 이동할 수 있게 합니다. HTML 정책·기관 링크, 검색과 저장의 가능한 범위를 유지합니다. JavaScript가 없을 때도 원문 링크가 남습니다. 3D가 떠야만 정보에 접근할 수 있는 구조로 만들지 않습니다.

장면은 입력·전환·리사이즈에 맞춰 렌더링하고 정지 상태에서는 프레임을 계속 생성하지 않습니다. 화면 밖·숨긴 탭에서는 렌더를 멈춥니다. 픽셀 비율과 그림자 해상도를 모바일에서 제한하되, 실기기 FPS·발열 측정 전에는 성능이 검증됐다고 표현하지 않습니다.

## 검증과 출시 판정

- 정책 10개가 실제 3D 조각과 HTML 버튼으로 연결되는지, 회전·펼침·조명·카메라 접근·전체 복귀가 실제 렌더를 바꾸는지 확인합니다.
- 320/375/414/768/1440px에서 글자·조작부·선택 요약의 겹침, 가로 넘침, 모바일 스크롤과 회전 전환을 확인합니다. 실제 캡처를 참고 영상과 비교해 공간감·재질·조작 목적을 판단합니다.
- 저장·메모·새로고침 복원·삭제·JSON 내보내기·저장소 오류·두 탭 동기화와 정책·기관 상세, 출처·의회 링크를 유지합니다. WebGL 실패·모션 감소·키보드·무스크립트도 검증합니다.
- `npm run check`, `npm test`와 배포 후 `scripts/verify-live.cjs`, 공개 URL을 대상으로 한 `npm run test:scene`을 사용합니다. 증거와 실행 환경·시각·revision은 `qa/`에 기록합니다.

이 문서는 구현과 검증 기준입니다. 테스트 통과는 사용자의 최종 미적 만족, 고객 행동 성과, 정책의 현재 효력을 입증하지 않습니다. 과거 화면별 배포·검토 결과는 Git 이력과 `qa/deployment.json`에서 확인합니다.
