# 치안 지도 — 실험 03

독립된 전역 지도 재실험용 정적 사이트 경로입니다. 기존 `sites/safety-map/`은 이 실험의 구현 기반이나 수정 대상으로 사용하지 않습니다.

## 목적

전체 화면의 Mapbox 지도를 중심으로 장소·도로 탐색, 검색, 확대·축소·이동, 바탕 지도 전환을 제공하는 경험을 만듭니다. 4차에서는 로마의 공개 근거 확인 상태를 같은 배포본에 추가합니다. 안전 판단을 자동화하거나 단정하지 않습니다.

## 사용자 경계

- 장소 탐색과 공개 안전 정보의 **부재**를 명확히 안내합니다.
- 안전 점수, 안전 경로, 실시간 사건, 위치 수집, 개인정보 전송을 만들지 않습니다.
- 신뢰할 수 있는 공개 데이터가 연결되기 전에는 `검증 근거 없음` 상태를 유지합니다. 이 상태는 안전·위험·범죄 발생 여부를 뜻하지 않습니다.
- 적격 입력이 0개일 때는 사용자 경험 기반 주의 신호, 지역 순위, 핀, 점수, 예측을 표시하지 않습니다.

## 구조

- `src/`: 사람이 편집하는 소스
- `dist/`: 정적 배포 산출물

이 경로에는 전체 화면 Mapbox 캔버스, 상단 서체 영역, 검색과 접근성 상태, 로마의 근거 상태를 둡니다. 4차는 새 앱을 만들지 않고 이 배포본을 확장합니다.

## 토큰·배포

`MAPBOX_PUBLIC_TOKEN` 값은 저장소, 소스, 테스트 출력, 보고서에 넣지 않습니다. experiment-03 전용 실행 설정 파일은 보호된 Gateway에서 생성하며, GitHub Actions 동기화는 이 파일을 보존합니다.

## 검증

새 경로만 존재하는지와 `sites/safety-map/**`가 변경되지 않았는지를 검사합니다. 이어서 로컬 동작 확인, 데스크톱·390px 상호작용, 레드 직접 시각 검증, 라이브 증거를 추가합니다.
