# LCML frontend implementation — 2026-11-11

담당 범위: `dashboard/office/`, `dashboard/vite.office.config.js`, `dashboard/package.json`의 `build:office`, 생성된 `dist/office/`. Collector·기존 대시보드 화면은 수정하지 않았습니다. 커밋·push는 실행하지 않았습니다.

## 구현 결과

- React/Vite 별도 `/office/` 진입점. 크림·테라코타, Pretendard, 넓은 사무실 장면, 네 층 엘리베이터, 실제 벽면 DOM 보드와 상세 패널.
- 층별 실제 태스크 요약, 세 저장소 Git, 프로젝트별 AARRR 선택, 전략/가치/가설, 질문 대기열·질문 티켓·대기 표현 설정, 전체 보기.
- 관측 세션 스프라이트, 출퇴근/보고 이벤트 중복 방지, 경과/막힘의 땀, 대기 커피/졸음, 근거 있는 소등, 리더 역할 이름표.
- 30초 no-store 폴링, 720초 신선도 경계, 원천 오류·HTTP 실패 시 정지, 오류/빈 상태/이미지 실패, 실제 0과 미측정 구분.
- 키보드 이동, reduced motion, 모바일 하단 층 선택, 12개 좌석을 넘는 세션의 상세 목록.

## 확인한 증거

- `node --test office/test/model.test.mjs`: 12/12 통과. 처음 9개 실패를 확인한 뒤 구현했고, 반복 원천 오류/closed 대기실/보고 자세 회귀 테스트도 실패→통과를 확인했습니다.
- `npm run build:office`: Vite 6.4.5, 성공, 경고 없음. 결과 JS 약 177.5 kB / gzip 57.2 kB, CSS 약 27.4 kB / gzip 6.4 kB.
- `git diff --check`: 통과.
- 루트 통합 담당자가 데스크톱·모바일 실제 렌더를 확인했고, 벽면 정렬과 레이아웃이 적절하다고 보고했습니다. 수정 피드백(피부 hue 제거, 보고 자세, 실제 태스크 보드, Git 출처, 미확인 개수)을 반영했습니다. 최종 브라우저·라이브 검증은 루트 통합 단계가 담당합니다.

## 남는 경계

- 소스가 제공하지 않은 AARRR 정의/업스트림 마지막 성공 시각은 미연결 또는 원천 설명으로 노출합니다.
- 공개 가능한 태스크/질문/전략 요약의 생성·검열과 세션 생존 판정은 Collector 책임입니다.
- 이 작업 자체는 배포 완료를 주장하지 않습니다. 통합 담당자가 실제 JSON과 배포 URL을 검증해야 합니다.
