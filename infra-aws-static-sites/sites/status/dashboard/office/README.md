# LCML Office

LCML은 회사의 실행 세션과 결정 대기 항목을 네 층의 사무실로 보여주는 읽기 전용 화면입니다. 제품실(지니), 고객실(세스고딘 CMO), 비즈니스실(SAM), 대표실(사용자)의 책임을 구분합니다. 실제로 관측된 세션만 사람으로 표시합니다.

## 실행과 검증

기존 `dashboard/`의 React 18 / Vite 환경을 재사용합니다. 추가 패키지는 없습니다.

```sh
cd /home/ubuntu/workspace/space/infra-aws-static-sites/sites/status/dashboard
node --test office/test/*.test.*
npm run build:office
npx vite --config vite.office.config.js
```

빌드는 `../dist/office/`만 교체합니다. 배포는 상위 Status README의 기존 S3/CloudFront 경로를 사용합니다. 로컬 정적 확인은 `../dist/`를 HTTP로 제공하고 `/office/`를 엽니다. 개발 Vite 서버에는 별도로 같은 출처의 `/office-live.json`이 필요합니다. 실행 환경의 자격증명이나 수집 원천에 브라우저가 직접 접근하지 않습니다.

## 데이터와 화면

- `/office-live.json`: schemaVersion 1. 10분 수집, 브라우저 30초 확인, 요청 12초 제한, 중복 요청 방지, no-store.
- 세션 source.state와 실제 관측 시각을 함께 확인합니다. 마지막 관측이 720초를 넘거나 원천이 실패하면 마지막 캐릭터 프레임을 정지합니다. 층 이동은 계속 가능합니다.
- 세션별 이벤트 큐가 같은 수집 구간의 도착·보고·퇴근을 순서대로 보여주고 마지막 이벤트가 끝나면 종료 캐릭터를 제거합니다. 최초 접속·중복 스냅샷·과거 스냅샷·오류 복구에서 과거 출퇴근/보고 이벤트를 재생하지 않습니다. 세션 목록에서 사라졌다는 이유만으로 퇴근 이벤트를 만들지 않습니다.
- Git은 로컬 관측과 원격 추적 브랜치 기준입니다. AARRR은 프로젝트 선택, 값·단위·기간·수집 상태와 원천 설명을 보여줍니다. 태스크·Git·지표도 실제 관측 시각 720초를 기준으로 신선도를 표시합니다. AARRR 단계별 관측 시각을 별도로 보여줍니다. 미측정·현재 확인 불가 값은 `—`, 신선하게 측정된 0은 `0`입니다.
- 대표실 질문은 오래 기다린 순서입니다. 연결된 세션이 없으면 사람 대신 질문 티켓으로 표시합니다. 자세 변경 10분/땀 40분 기본값은 대표실 상세에서 변경할 수 있습니다.
- 화면상의 세션 좌석은 최대 12개, 대표실 질문 세션은 최대 8개입니다. 모든 관측 세션은 우측 ‘관측된 세션’ 목록에서 상세를 열 수 있습니다.
- `day.phase=closing|closed`와 `closedAt` 근거가 있을 때 소등합니다. 작업·대기·막힘·보고·미확인 세션 또는 질문이 있는 방은 켜둡니다. 새로운 열림→마감 관측에서만 네 구역이 차례로 어두워집니다. 첫 관측부터 닫힌 상태면 소등 과정을 재생하지 않습니다. 브라우저가 임의로 마감 시각을 정하지 않습니다.
- `prefers-reduced-motion`, 키보드 층 이동(위/아래/Home/End), 포커스, 모바일 하단 층 선택을 지원합니다.

## 이미지 계약

`public/assets/office.png`는 1536×1024 배경입니다. 화이트보드는 뒤쪽 왼쪽 벽에 DOM으로 배치합니다. 작은 벽면 글자의 전체 내용은 우측 상세에서 읽습니다.

`public/assets/characters.png`는 4열×3행 투명 스프라이트입니다. 열/행 좌표는 0부터 시작합니다.

| 행 | 열 | 상태 |
| --- | --- | --- |
| 0 | 0–3 | 타자 프레임 |
| 1 | 0–1 | 걷기 |
| 1 | 2 | 보고 자세 |
| 1 | 3 | 서서 커피 |
| 2 | 0–1 | 앉아서 커피 / 졸음 |
| 2 | 2 | 오래 기다리는 자세 |
| 2 | 3 | 중립 자세 |

이름표 색으로 세션을 구분하며 피부색은 변경하지 않습니다. 별과 땀은 별도 DOM입니다. 대표 리더의 실제 세션이 없으면 역할 이름표만 남습니다.

## 운영 경계

로그인 없는 기존 Status의 `/office/` 경로이며, 공개 가능한 요약만 수집기가 공급해야 합니다. UI에는 샘플 데이터나 폴백 가상 세션이 없습니다. 테스트 fixture는 테스트 코드 안에만 있습니다. 세션 생존 판정·질문 공개 요약·지표 정의의 정확성은 수집기 계약에 의존합니다. 프로젝트 설정에 정의된 AARRR이 없으면 화면에서 새 지표를 만들어 채우지 않습니다.

원천 수집과 배포 방법은 상위 [Status README](../../README.md), 수집기 계약은 승인된 [구현 계획](../../../../../docs/superpowers/plans/2026-11-11-lcml-office.md)을 참고합니다.
